# ML pipeline dependencies.
#
# PINNED ON PURPOSE. server/scoring_loader.py imports ml.pipeline into the
# SERVER's own process, so these become the server's libraries too - install
# them into the environment the server runs in, not a separate venv.

# --- the stack every model was validated against ---------------------------
torch==2.13.0
torchvision==0.28.0
safetensors==0.8.0

# transformers is the load-bearing pin. RT-DETRv2 stores its per-layer
# prediction heads TIED. Version 5.15.1 expects them untied, fills the gap
# with RANDOM weights, and the ear_tag path reads decoder layer 1 - one of
# the layers it randomises.
#
# It does not crash. It returns a confident-looking 0.62 detection with a box
# outside the image, and the value changes on every process start. Under
# 5.0.0 the heads load correctly - verified by loading in three separate
# processes and comparing the weights byte for byte.
#
# Do not relax this to >=. server/preflight.py FAILS if it is not exactly
# 5.0.0, because a wrong version here stays invisible until someone actually
# looks at a bounding box.
transformers==5.0.0

# DINOv2 backbone for breed/group verification, and HRNet-W32 for keypoints.
# Both are plain torch on top of timm.
timm==1.0.28

opencv-python
numpy
Pillow
